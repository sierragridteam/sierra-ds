# SIERRA design system

Shared Astro components, CSS tokens, and browser UI helpers.

```sh
pnpm add @sierragridteam/design-system
```

Import components from `@sierragridteam/design-system/components/Button.astro`,
styles from `@sierragridteam/design-system/styles/global.css`, and browser helpers
from `@sierragridteam/design-system/lib/controls`.

See https://github.com/sierragridteam/sierra-ds for the demo and usage documentation.
